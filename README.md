# Churn_Analysis-Customer_Intelligence
End-to-end subscriber churn analysis using SQLite (customer_churn.db) and Python (Pandas, NumPy, Matplotlib, Seaborn). Cleans and merges customer, subscription, and support data, engineers churn/tenure/risk features, calculates 28.57% churn rate and $73.94 lost MRR, and visualizes trends across plans, contracts, regions, and escalations.
